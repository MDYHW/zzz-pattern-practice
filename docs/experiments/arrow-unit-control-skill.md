# 환영의 화살 유닛 — 수동 관측과 최초 실험 프로필

2026-09-22 수동 녹화7개를 분석하고 **진입 RMB + 후속 Space4**의 실험 프로필을 만들었다. 공식 표시명은 **「A-H0L0」형 스마트 전술 구조체·환영의 화살 유닛**, 영문은 **A-H0L0 Type Intelligent Tactical Construct - Mirage Archer Unit**이다. 짧은 이름은 **Mirage Archer Unit**이 맞다. 편성은 **아리아→남궁우→수나**, 시작은 **아리아**다.

최초 값은 수동 성공점·실패점에서 제안한 **탐색 후보**이며 양끝 성공을 측정한 구간이나 웹 채택값이 아니다. [프로필](../../tools/experiment/profiles/mirage-archer-unit-attack-09.json)과 [수동 판독 근거](../evidence/mirage-archer-unit-manual-20260922.json)를 따른다. 이름 정정으로 기존 정적 조사 파일명·출처 식별자는 바꾸지 않았다.

현행 서비스 채택은 아래 **대표 영상과 웹 반영** 절을 따른다. 최초 탐색값과 당시 다음 행동은 현재 단계로 반복하지 않는다.

## 최초 프로필 검사와 당시 다음 실험

실제 새 프로필과 C# 감지기로 메뉴 원점이 무효인6번을 제외한 **6개 전체 영상**을 재생했다. 사람이 확인한 출현·소멸 범위 안에서 감지했고 범위 밖 일치가 없어6개 모두 통과했다. 기존 노란 문구 템플릿을 그대로 쓴다. 원본과 오프라인 재생에서는 확인됐지만 실제 캡처 지연·입력 제출과 게임 성공은 다음 실행에서 확인한다.

실험기 빌드, 새 프로필9개 가짜 입력 조합과 공통148개 검사를 통과했다. 원본·사용자 실행 위치의 UI smoke와 표시를 확인했으며 실제 입력 체크는 꺼져 있다. 준비 동작 없는 수동WASD 프로필의 안내 누락도 수정했다. 사용자 실행 위치에 프로필·실행파일·사용법을 반영하고 기존22개 설정/프로필/기록JSON의 해시를 보존했다. 전체5개 프로필·서비스 영상 정렬 검사를 완료했다고 보고하지 않으며 이번 변경의 검사 범위는 새 프로필과 공통 실행부다.

첫 실행은 **다섯 행 모두 기준값1회**다. 정상 경로 전체 성공 후 전체 이른 값1회·전체 늦은 값1회로 양쪽을 탐색하고, 실패하면 처음 실패한 행만 분리해 조정한다. 기존 녹화의 후속 큐 비교를 이미 했으므로 같은 목적의 수동 녹화를 다시 요구하지 않는다. 동시에 바꾼 결과는 독립 단일행 경계 측정과 구별한다. 세 회만으로 확정 경계를 선언하지 않으며, 실제 결과에 따라 필요한 행에만 후속 실험을 배정한다.
