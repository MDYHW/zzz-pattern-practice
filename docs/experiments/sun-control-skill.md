### 채택 근거·혼재·추가 측정 판단

- **기본:** 15·20회 `2200/4500/6850/7800`, 27회 `1900/4900/6500/8150`이 전체 성공이다. 30회 최종 기준도 전체 성공이고 대표 영상과 일치한다. 6450은 채택한 진입1900에서도 실패(8·29회), 4950은1타 실패(28회)다. 7750은 성공(16회)과 선행 성공 뒤 실패(19회)가 혼재해7800을 택했다. 8200은 성공과 실패가 있어8150으로 좁혔다.
- **기본 혼재 유지:** 25·26회는 같은 `1900/4850/6500/8150`에서1110/1111이다. 27회는1타만4900으로 바꾸고1111이다. 진입2200도18회 실패가 있지만15·20회 성공이다. 18회의 입력 제출 끝 지연이 약14ms였다는 관측만으로 실패 원인을 확정하지 않는다. 6500의 실패는 진입1850 등 조건도 다르므로 채택 조합1900의 성공과 함께 해석한다.
- **융합:** 41회 `2250/5100/7550/9350/11400`, 50·52회 `2150/5500/7150/9750/10950`, 43회 `2050/5300/7150/9750/11050`이 전체 성공이다. 54회 최종 기준은 영상까지 전체 성공을 확인했다. 5050·7600·11450에서 해당 동작 실패가 있어 그 안쪽을 택했다. 51회3타9800은 성공했지만4타10950이 실패했고, 50·52회3타9750에서는 마지막까지 성공하므로 앞뒤 간격을 보존한다.
- **융합 혼재 유지:** 34·35회 같은 입력에서10101/11111이며1타5100은 무조건 성공 경계가 아니다. 진입2050도43~46회 성공과47회 실패가 혼재한다. 뒤의1타5500 변경이 앞선 진입 실패의 원인이라고 해석하지 않는다. 선행 실패 뒤 결과를 각 동작의 독립 경계로 사용하지 않는다.

따라서 채택값은 특정 경로에서 반복 연습에 사용할 **실용 범위**이며 내부 최대 허용 구간이나100% 성공 보장이 아니다. 사용자의 최종 설정은 반복된 바깥 실패와 양끝 교차를 반영하고 있고, 혼재만 없애려 같은 실험을 반복하거나 전체 폭을 일괄 축소할 근거는 부족하다. 독립 읽기 전용 검토도 이 조건부 채택과 추가 필수 측정 없음에 동의했다. 다른 거리·파티·지원 경로에서 재현되는 새 반례가 생기면 해당 동작과 선행 조건만 다시 본다.

## 종료 정리와 남은 사항

사용자 승인으로 대표 서비스 원본2개와 대응30·54회의 원본/결과/감지 이미지, 서비스 자산, 현행 프로필·공통 도구를 유지한다. 나머지23개 녹화와52회 상세 로그, 중간 프레임·임시 클립·일회성 스크립트·검사/빌드 출력·대체된 초기 후보 설명은 백업 없이 제거했다. 보존 파일·정리 결과는 [정리 기록](../evidence/experiment-cleanup.json)을 따른다. 삭제된 자료의 경로·해시가 과거 관측 요약에 있더라도 원본이 남아 있다는 뜻은 아니다.

융합 진입의 웹 추가 여유2025–2275ms만 실제 게임 검증 대기로 유지한다. 이는 종료를 막는 추가 실험 요구가 아니며 새 반례나 사용자의 재개 요청이 있을 때 해당 구간만 확인한다. 다른 파티·거리·지원 경로 전체에 성공을 보장하지 않는다.

## 재사용할 조사 결론

외부 시연은 패턴 구성과 내부 상태의 연결에 사용하고, 파티·진입 경로·육안 원점이 다른 반응 시각을 실행기 입력값으로 직접 옮기지 않는다. 최초 외부 추정은 로컬 진입 실패와 수동 영상에 의해 폐기됐다. [일반 외부 시연](https://www.youtube.com/watch?v=2hCKkHN4eTk)은 교대 진입, [융합 외부 시연](https://www.youtube.com/watch?v=dJ3YPGKspeQ)은 피격 진입이어서 이번 RMB 정상 경로와 같지 않았다.

21개 수동 영상에서는 준비 피해·진입 피해·첫 지원 피해·최종 완벽 표시를 분리했다. 준비 공격을 맞고도 진입은 가능하며, 최종 완벽 표시가 진입 무피격이나 모든 지원의 무피격을 입증하지 않는다. 융합 첫 지원 벨리나에서 피해가 관측된 경로와 현재 아리아↔레미엘 대표를 합쳐 경계를 만들지 않는다. 입력 영역의 X자 효과도 짧은 키 입력으로 잘못 셀 수 있어 화면과 함께 확인한다.

공용 문구 최초 일치와 확정 프레임, 입력 오버레이와 OS 제출·게임 수용은 다른 근거다. 내부 상태 좌표의 동일한 폭을 근거로 모든 동작을400ms로 채우지 않는다. 실험은 기준 완주 후 양끝 교차·실패한 동작과 선행 조건을 좁혀 조사하며, 재사용할 성공과 혼재 반례를 함께 남긴다.

## 내부 연결과 비교

설치 원본의 한 능력 번들에서 `Mutant_AidTriggerControl`, `Mutant_HC_Init`와 일반·HC 관리자를 추출했다. `Monster_Mutant`는 일반 관리자, `HardCore` 태그가 있는 `Monster_Mutant_HC`는 Init에서 `Bool_IsHC=true`와 HC 관리자를 함께 적용한다. 후자의 공식 영문 키는 `Integrated - Phaethon of the Scorched Horizon`이다. 따라서 내부의 HC는 융합형에 연결되며, ‘절망’이라는 모드 이름만으로 형태를 판정하지 않는다. 출처·해시·객체 ID는 [내부 근거](../evidence/sun-internal-20260923.json)를 따른다.
