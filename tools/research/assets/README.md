# Static timing curve replay

`extract_curve.py` reads one named curve from an explicitly supplied original `.blk` file. It does not start the game or write to its installation. Its output identifies the source block hash, bundle offset and size, serialized node hash, object ID and offset, and curve values. Curve input coordinates are not seconds or physical key acceptance boundaries.

The default known source for the current 3.2 installation is `3436993579.blk`, bundle offset `48754`, size `20190`, SHA-256 `2d3ee1ee74a76adec269fc5997164d49e31c64577207215cd9d12ea5206767db`. Pass its location with `--block` and the hash with `--block-sha256`; no path is embedded in the program.

Required arguments: `--block`, `--block-sha256`, `--offset`, `--bundle-size`, `--name`, `--crypto-source`, `--mhy-source`, and `--ooz-dll`. `--output` creates a new JSON file at a chosen path; it refuses existing files and input aliases. Otherwise JSON goes to stdout. The curve name used for the existing evidence is `Monster_Execute_AvatarEvade_WitchSlowDownCurve`.

The three decoder inputs come from [Escartem/AnimeStudio](https://github.com/Escartem/AnimeStudio), tree `02994d5c30a43d0d5c5124557ec361ccbbad24c0`, under the [MIT license](LICENSE-AnimeStudio.txt): `AnimeStudio/Crypto/CryptoHelper.cs`, `AnimeStudio/MhyFile.cs`, and `AnimeStudio.Libraries/AnimeStudio.Ooz.dll`. Their exact SHA-256 hashes are pinned in the program. The tool decodes verified byte snapshots and loads the native DLL from a private verified snapshot. The files are intentionally not included. The decoder needs Python 3.11 or later and `cryptography`; local replay used Python 3.12.14 and cryptography 50.0.1. The Ooz DLL is Windows x64, so this raw-block path has only been verified on Windows x64. No package is installed by this program.

Run the pure synthetic checks with `python -m unittest discover -s tools/research/assets -p 'test_*.py'`. They cover valid key parsing plus malformed object, curve, bundle, and decoder input bounds. The tool emits the serialized SHA-256 and key values; a local replay was compared with the prior evidence and matched serialized SHA-256 `64d26bdcbfea46ea4714856730b71d9eb7ec8aabd288be9d537b4a573e1bd2fd` and all four keys. This one-curve path does not reproduce the complete timing catalog, the TimeSlow configuration, live hotfix choice, or the game's input judgement.
